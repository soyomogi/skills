# 自分用の開発タスクノート

## task
Obsidianのタスクノート「Tasks/anti-slop-reader-audit.md」の本文を清書する。必要な記録と次の作業を残し、本文だけを返す。

## input
### 関連ノートで整理済みの背景
anti-slopは文書の不要な説明を削るskill。文書の読者によって、必要な背景説明が異なる。

### 清書対象
このノートはanti-slopの読者判定を改善する作業のために作成されました。AIが会話からまとめています。anti-slopは文書の不要な説明を削るskillで、不要な説明を読むことは負担になります。試験では3回中2回、修正文の末尾に効能の再説明が1文残りました。変更案は、文書の用途から読者を推定し、明示された読者と共有済みの事情を優先することです。次はタスクノート・PR説明文・チーム向け報告を各2回、計6回で検証します。変更案の効果は未検証です。この変更で文書作成をさらに改善していきます。

## expected

想定読者は依頼者自身。用途を手がかりに推定し、関連ノートで整理済みの説明を繰り返さない。

保持する内容:

- 3回中2回、末尾に効能の再説明が1文残ったという検証記録
- 用途からの読者推定と、明示された読者・共有済みの事情の優先という変更案
- 3種類の文書を各2回、計6回で検証する次の作業
- 変更案の効果は未検証

削除する内容:

- ノートの目的宣言とAIによる作成経緯
- 整理済みのskill紹介・読む負担の説明
- 抽象的な効能の締め

既知の背景説明と、後から確認するための具体的な検証記録を区別する。ノート本文の作成依頼をskill自体の改善依頼と扱わない。
