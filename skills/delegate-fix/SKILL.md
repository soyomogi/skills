# Delegate Fix

1. 直前の会話から指摘、修正案、対象、完了条件をまとめる。
2. 委譲先は指定に従う。未指定なら `$herdr` で現在の workspace の `🤖` タブにいるエージェントを特定する。
3. 送信文の冒頭に「これはあなた宛ての実装依頼です。あなたが修正・検証を担当してください」と明記する。送信内容は実装に必要な文脈・修正内容・検証・完了条件に絞り、`$delegate-fix` など委譲に使ったスキルの呼び出し表記や、委譲操作の経緯は含めない。利用可能な標準のメッセージ送信機能で委譲先へ送る。
4. 送信結果を確認し、委譲先と依頼内容を簡潔に報告する。
