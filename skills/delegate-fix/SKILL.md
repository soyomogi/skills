# Delegate Fix

1. 直前の会話から指摘、修正案、対象、完了条件をまとめる。
2. 委譲先の指定があれば従う。未指定なら、導入先の補足に従って委譲先を探す。委譲先を一意に特定できなければ、送信前にユーザーへ宛先を確認する。
3. 送信文の冒頭に「これはあなた宛ての実装依頼です。あなたが修正・検証を担当してください」と明記する。送信内容は実装に必要な文脈・修正内容・検証・完了条件に絞り、`$delegate-fix` など委譲に使ったスキルの呼び出し表記や、委譲操作の経緯は含めない。宛先には利用可能な標準のメッセージ送信機能で送る。
4. 送信結果を確認し、委譲先と依頼内容を簡潔に報告する。
