# Delegate Fix

1. 直前の会話から指摘、修正案、対象、完了条件をまとめる。
2. 委譲先の指定があれば、そのエージェントを使う。指定がなければ `$herdr` を使い、現在の workspace の `🤖` タブで起動中のエージェントを特定する。候補が複数ある、または見つからない場合はユーザーに確認する。
3. 委譲先が会話を共有していなくても実行できるよう、必要な文脈と修正・検証の指示を送る。Herdr では標準の `herdr agent prompt` を使う。送信前に相手の状態を確認する。
4. 送信結果を確認し、委譲先と依頼内容を簡潔に報告する。
