# Session Start

1. ユーザーの指定や作業環境の指示から、作業対象の Obsidian ノートを特定する。対象を絞れない場合は確認する。
2. ノートの目的、現在の情報、直近の作業ログから、成果、判断、検証結果、未完了事項を把握する。
3. 対象がタスクノートなら、現在の状態と次回のアクションを確認する。`next_action_detail` があれば、今回の指示に照らして最初の具体的な手順を整理する。
4. 対象ノート、現在の状態、未確認事項、次の一手を簡潔に報告する。作業の実行も依頼されていれば、そのまま着手する。
