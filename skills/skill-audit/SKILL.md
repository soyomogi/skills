# Skill Audit

skillの作成・変更の作法と、重複の判断基準は skill-authoring に従う。このskillは棚卸しの監査と、その結果に基づく修正を行う。

## 対象

- 対象はskill群（自作skillの全件）と、その依存skill（依存定義と、本文で参照しているskill）。
- 参照するのは各skillの原本だけとする。
- 修正の対象は、導入先が管理するものだけとする。

## 手順

1. 対象のskill群と依存skillを全件列挙し、原本を読む。
2. 各skillについて、担っている規則・手順・判断基準を書き出す。
3. 重複を判定する。重複は、関係する全ての場所から根拠となる文を短く引用して裏付けられたものだけを挙げる。
4. 過去の棚卸しで判断済みの重複を除き、未判断の重複だけを対象にする。
5. 未判断の重複を修正する。修正方法は、各管理元の規定の方法に移譲する。「要確認」の重複は修正せず、報告だけにする。
6. 重なっている内容、重複の程度（完全／部分）、寄せ先、修正内容を報告し、判断済みとして記録する。
