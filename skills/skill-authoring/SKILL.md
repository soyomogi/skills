# Skill Authoring

## 手順

1. 目的と期待する振る舞いを定め、指示ごとの責務と適用範囲を分ける。
2. 下の配置規則に沿って記入先を選ぶ。編集する元ファイルと配布されたコピーを区別し、元ファイルを編集する。
3. 必要な場面で指示が届くように、読み込み条件と参照を揃える。
4. 極力抽象的な規則として簡潔に書く。判断に必要な条件と完了基準は残し、同じ規則の重複を避ける。
5. 共有ファイルはskillshareのextrasで配布する。Claude・Codexの両方に同期し、配置・参照・動作を検証する。確認できた範囲と未検証の範囲を区別して報告する。

## 配置規則

- AGENTS.md: その適用範囲で継続して必要な共通規則。
- skill本体: 呼び出された作業に固有の手順と判断基準。
- 補足資料: 一部の場面で必要な詳細。必要になる箇所に読み込み条件と参照先を置く。
- trigger: 指示を読み込む条件と参照先。
- hooks: 特定のイベントで機械的に実行する処理。
