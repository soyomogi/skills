# Skill Authoring

## 手順

1. 目的と期待する振る舞いを定め、指示ごとの責務と適用範囲を分ける。
2. 下の配置規則に沿って記入先を選ぶ。編集する元ファイルと配布されたコピーを区別し、元ファイルを編集する。
3. 必要な場面で指示が届くように読み込み条件を揃える。読み込み方法は同期設定と実際の動作で確認し、確認できた内容だけを書く。
4. 極力抽象的な規則として簡潔に書く。判断に必要な条件と完了基準は残し、同じ規則の重複を避ける。descriptionは実際の役割と呼び出し条件に合わせる。
5. Claude・Codexの両方に同期し、元ファイルとの一致、参照先への到達、条件に応じた動作を検証する。確認できた範囲と未検証の範囲を区別して報告する。

## 配置規則

- 共通指示: skillの呼び出しに関係なく適用範囲内で継続して使う規則。extrasに置く。
- skill本体: skillを呼んだときに実行する固有の手順と判断基準は、各skillsに置く。
- supplement: skillを読んだときに適用する規則。extrasに置く。
- trigger: skillを呼ばなくても特定の条件で適用する規則。条件と動作を対応させる。
- hooks: 特定のイベントで機械的に実行できる処理は、hooksに置く。
