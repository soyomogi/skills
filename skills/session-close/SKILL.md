# Session Close

1. 次のエージェントが元の会話を読まずに再開できるよう、成果、決定とその理由、検証結果、再開に必要な作業環境（リポジトリ、作業ディレクトリ、ブランチなど）、残作業と未確認事項を整理する。残作業があれば、最初に操作する対象をパスや URL などで特定し、最初に行う操作を記す。
2. 引き継ぎ文書の作成を依頼されたら、整理した内容を文書にまとめて保存する。作業を締めるときは、作業対象の記録を更新する。
3. 対応するタスクがあれば、現在の状態と次回のアクションを更新する。
4. 記録を読み返して再開に必要な情報が揃っていることを確認し、保存先と引き継ぎ事項を簡潔に報告する。
